## Features

- **Modern Minimalist UI**: Rounded cards, Light and Dark mode toggle (`◐`), and `#ADFF2F` accents powered by native Edge WebView2.
- **Auto-Fire Ticket Sniper**: Lock your **City**, **Direction** (`Inbound` / `Outbound` / `Both`), **Stops**, and **Departure Times**. At opening time, `Stride` pre-warms your session, burst-polls availability, and fires parallel holds + confirmation automatically.
- **Browse Trips & Stops**: Filter student buses by direction and city, view live 1-second PKT countdowns, and click any trip card to inspect all stops.
- **Booked Tickets**: View confirmed student tickets with `#ticket_code`, stops, PKT departure time, passenger name, and price.
- **MWALLET Recharge**: Top up G-Bux directly with live limit checking and JazzCash confirmation support.
- **One-Click Windows Install & Uninstall**: Installs cleanly to `AppData\Local\Programs\Stride`, creates Desktop and Start Menu shortcuts (searchable in Windows Search), and registers in Windows Installed Apps.
- **Self-Updating Executable**: Checks GitHub Releases on startup, downloads updates in-place, and auto-restarts.

## Quick Start

1. Download **`stride_installer.exe`** from the [Latest Release](https://github.com/misbah-ullah01/giki-transitpulse/releases/latest).
2. Double-click `stride_installer.exe` and choose **Install to C: Drive & Launch** (or **Run Portable Once**).
3. Sign in with your GIKI reg number (e.g. `2024297`) or `@giki.edu.pk` email.

*(Optional: launch with `stride.exe --cli` to use the terminal shell mode.)*
